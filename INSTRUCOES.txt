---------------------------------------------------------------------
 PASSO 2 - CRIAR AS TABELAS NO NEON (obrigatorio, 1 vez)
---------------------------------------------------------------------
1. Abra https://console.neon.tech  -> seu projeto -> SQL Editor
2. Abra o arquivo  SQL-NEON-modulo-ia.sql  (esta na raiz do zip) no Bloco
   de Notas, selecione tudo (Ctrl+A), copie (Ctrl+C)
3. Cole no SQL Editor e clique em RUN
4. Deve terminar sem erro. Pode rodar de novo se precisar: ele usa
   "IF NOT EXISTS" e nao apaga nada.

Alternativa pelo PowerShell (se tiver o .env com DATABASE_URL na pasta):
npm run db:migrate:ai

---------------------------------------------------------------------
 PASSO 3 - VARIAVEIS NO CLOUDFLARE
---------------------------------------------------------------------
Cloudflare Dashboard -> Workers & Pages -> trading-pro -> Settings ->
Variables and Secrets -> Add

OPCAO A (GRATIS - recomendada agora):
  1. Pegue uma chave gratis em https://aistudio.google.com/apikey
  2. Adicione:
     AI_PROVIDER      = gemini            (tipo: Text)
     GEMINI_API_KEY   = <sua chave>       (tipo: SECRET)
     GEMINI_MODEL     = gemini-2.5-flash  (tipo: Text, opcional)

OPCAO B (OpenAI - paga, minimo US$5 de credito):
     AI_PROVIDER      = openai
     OPENAI_API_KEY   = <sua chave sk-...>   (tipo: SECRET)
     OPENAI_MODEL     = gpt-4.1-mini         (opcional)

OPCAO C (so para ver as telas, sem gastar nada):
     AI_PROVIDER      = mock

OPCIONAL (protecao simples das rotas de IA, ja que o app nao tem login):
     APP_API_TOKEN    = <uma senha qualquer que voce inventar>  (SECRET)
  Depois, na tela "Analise Macro IA", clique em "token" (canto superior
  direito) e cole a mesma senha. Fica salvo no navegador.

Depois de salvar as variaveis: Deployments -> "Retry deployment" (ou
faca qualquer novo push) para o Worker reler as variaveis.

As chaves ficam SO no backend (Worker). Nunca va para o navegador e nunca
sao commitadas (.env esta no .gitignore; .env.example tem so placeholders).
